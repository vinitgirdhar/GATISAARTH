# GatiSaarth — Official App Landing Page

Interactive, high-performance web showcase and release distribution portal for **GatiSaarth** (गतिसार्थ) — an intelligent, software-defined dead reckoning navigation system for Android smartphones.

---

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (comes with Node.js)

### 1. Install Dependencies
```bash
# Navigate to the landing directory
cd landing

# Install required packages (Vite)
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
By default, the Vite dev server starts at:
👉 **[http://localhost:5173/](http://localhost:5173/)**

To expose the server on your local Wi-Fi / LAN (to view on your phone):
```bash
npm run dev -- --host
```

### 3. Build for Production
```bash
npm run build
```
This generates the optimized, production-ready static assets in the [`dist/`](./dist/) folder.

### 4. Preview Production Build Locally
```bash
npm run preview
```

## ✨ Features Included on the Landing Page

1. **Launch Video Theater**: Seamless embedded video player for the high-impact launch showcase (`landing_gatis.mp4`).
2. **Live Outage Simulator (Lab)**: Interactive visualizer demonstrating vehicle dead-reckoning trajectory through tunnels and GNSS-denied zones.
3. **Interactive Drift Calculator**: Compute and compare estimated position drift across Classical IMU vs. GatiSaarth 15-state ES-EKF.
4. **App Screens Showcase**: Interactive carousels displaying real Android UI components (Dashboard, Outage Alert, Sensors Tab, Offline PMTiles Maps).
5. **Direct APK Download**: One-click download button pointing to the bundled release APK in `public/`.
6. **Cybernetic Canvas & Sound Design**: Procedural particle network canvas with synthesized Web Audio API sound effects (toggleable on/off).

## 🛠️ Customization & Updating Assets

### Updating the Android APK
When a new version of the Android app is compiled in `../frontend`:
1. Copy the generated `.apk` into `public/`:
   ```bash
   cp ../frontend/build/app/outputs/flutter-apk/app-release.apk ./public/gatisaarth-v1.0-release.apk
   ```
2. Verify the download link in [index.html](index.html) points to `/gatisaarth-v1.0-release.apk`.

### Updating Branding & Video
- **Video**: Place the updated MP4 file into `public/` and adjust the `<source>` tag in `index.html`.
- **Logos & Icons**: Replace the files in `public/assets/icons/`.

## 🌐 Deployment

The `dist/` directory contains pure static HTML, CSS, and JS. It can be deployed immediately to:
- **Vercel**: Run `vercel` or link this subfolder.
- **Netlify**: Set base directory to `landing` and publish directory to `landing/dist`.
- **GitHub Pages**: Build with `npm run build` and deploy `landing/dist`.
- **Nginx / Apache / Caddy**: Point your root to the `landing/dist` directory.
