# Brag Plan: GatiSaarth

## What is this app?
GatiSaarth is a privacy-first Android navigation system that keeps estimating a vehicle's position when GNSS disappears, using only phone sensors, offline maps, and on-device models.

## The angle
Treat a tunnel as the product demo: the satellites vanish, but the route does not. The edit moves from a stark failure statement into an elegant recreation of GatiSaarth's real tunnel-test flow, then lands on measured evidence and privacy.

## Hook (first 2-3 seconds)
Against near-black, a blue verified route reaches a tunnel mouth and the line cuts out. Large copy: “GPS disappears.” A red inertial path continues through the darkness as “You don’t.” arrives.

## Key moments (the middle)

- Recreate the app's map dashboard with a scaled accuracy ring, vehicle puck, and “GNSS locked” capsule.
- Simulate “Tunnel test”: the capsule changes to “Dead Reckoning Active”, the verified blue trail becomes dashed red, and the uncertainty ring expands honestly.
- Show the measured simulation result: NHC reduced 60-second outage drift from 15.4% to 1.36% (11× improvement).

## Outro / punchline
“Navigation beyond satellites.” resolves into the GatiSaarth wordmark and “100% on-device · zero cloud reliance.”

## User flow worth showing
Drive with GNSS lock → enter a tunnel and switch to dead reckoning → continue along the curved route with visible uncertainty and smooth reacquisition.
